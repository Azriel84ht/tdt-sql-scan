Preguntas Frecuentes

¿Qué es exactamente Data Flow Visualizer?

Es una herramienta de software que analiza ficheros de script BTEQ de Teradata y genera automáticamente un grafo visual e interactivo. Este grafo te ayuda a entender el flujo de datos y la lógica de ejecución de tus procesos ETL de una forma mucho más intuitiva que leyendo el código.

¿Necesito instalar algo en mis servidores?

No. Nuestra aplicación funciona de forma completamente independiente. Solo necesitas subir tus ficheros de script (.bteq) a través de nuestro interfaz web. No requerimos acceso a tus bases de datos ni a tus sistemas.

¿Es seguro subir nuestros scripts?

Sí. La seguridad es nuestra máxima prioridad. Los scripts se procesan en memoria en nuestros servidores seguros y no se almacenan permanentemente a menos que tú lo decidas. Utilizamos encriptación de extremo a extremo para proteger tus datos.
