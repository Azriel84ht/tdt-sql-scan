# parser-core Module Documentation

## Purpose

The `parser-core` module serves as the foundational component for all SQL parsing activities within the TDT SQL Scan project. It defines the core interfaces, abstract classes, data structures, and utility methods that are common across different types of SQL statements (DDL, DML, SELECT, etc.). This module ensures a consistent representation of parsed SQL elements and provides essential tools for building more specialized parsers.

## Key Components

### Interfaces

*   **`QueryParser`**
    *   **Description:** An interface that defines the contract for any SQL parser in the system. Each concrete parser (e.g., for SELECT, CREATE TABLE) must implement this interface.
    *   **Methods:**
        *   `boolean supports(String sql)`: Determines if the parser can handle the given SQL query.
        *   `SQLQuery parse(String sql)`: Parses the SQL query and returns a concrete `SQLQuery` object (an Abstract Syntax Tree representation).

### Abstract Classes

*   **`SQLQuery`**
    *   **Description:** An abstract base class for all types of parsed SQL queries. It encapsulates the original SQL string and defines an enumeration for query types.
    *   **Enum `Type`:** Defines various SQL query types such as `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `CREATE_TABLE`, `CREATE_INDEX`, `DROP_TABLE`, `DROP`, `ALTER`, etc.
    *   **Methods:**
        *   `abstract Type getType()`: Returns the specific type of the SQL query.
        *   `String getSql()`: Returns the original SQL string that was parsed.

### Data Structures (AST Nodes)

These classes represent various components of an SQL query, forming the nodes of the Abstract Syntax Tree (AST) generated by the parsers.

*   **`SQLAssignment`**
    *   **Description:** Represents a single assignment operation, typically found in `UPDATE` statements (e.g., `column = expression`).
    *   **Fields:** `column` (String), `expression` (String).

*   **`SQLCondition`**
    *   **Description:** Represents a logical condition, commonly used in `WHERE`, `HAVING`, or `QUALIFY` clauses.
    *   **Fields:** `expression` (String).

*   **`SQLJoin`**
    *   **Description:** Models an SQL `JOIN` operation between two table references.
    *   **Enum `Type`:** Defines various join types (`INNER`, `LEFT`, `RIGHT`, `FULL`, `CROSS`, `UNKNOWN`).
    *   **Fields:** `type` (Type), `left` (SQLTableRef), `right` (SQLTableRef), `condition` (String - the `ON` or `USING` clause expression).

*   **`SQLOrderItem`**
    *   **Description:** Represents an individual item within an `ORDER BY` clause.
    *   **Enum `Direction`:** Defines sorting directions (`ASC`, `DESC`).
    *   **Fields:** `expression` (String), `direction` (Direction).

*   **`SQLTableRef`**
    *   **Description:** Represents a reference to a table or a subquery, including an optional alias.
    *   **Fields:** `expression` (String - the table name or subquery text), `alias` (String - the alias, if present).

### Exceptions

*   **`SQLParseException`**
    *   **Description:** A custom runtime exception thrown when a syntax error or other parsing issue occurs during SQL processing.

### Utility Classes

*   **`SQLParserUtils`**
    *   **Description:** Provides a collection of static utility methods to assist in common SQL parsing tasks. These methods help in extracting specific parts of an SQL string based on keywords and handling parenthetical depth.
    *   **Key Methods:**
        *   `extractBetweenKeywords(String sql, String startKeyword, String endKeyword)`: Extracts content between specified keywords, handling nested structures.
        *   `extractAfterKeyword(String sql, String keyword, String endKeyword)`: Extracts content after a keyword up to an optional end keyword.
        *   `splitTopLevel(String input, String delimiter)`: Splits a string by a delimiter, respecting parentheses to avoid splitting within nested expressions.
        *   `findTopLevelKeyword(String sql, String keyword, int startIndex)`: Finds the first occurrence of a keyword at the top level (outside parentheses).
        *   `getFirstWord(String s)`: Extracts the first word from a string, cleaning trailing punctuation.
        *   `extractTableFromExpression(String expression)`: Extracts the base table name from an expression that might include aliases.
        *   `extractTableName(String sql, String keyword)`: Extracts a table name following a specific keyword.

## Functionality

`parser-core` establishes the fundamental framework for SQL parsing. It defines how SQL queries are represented in a structured, object-oriented manner (AST) and provides the basic tools necessary for breaking down complex SQL strings. Other parser modules build upon these core definitions to implement specific parsing logic for their respective SQL statement types.

## Dependencies

This module has no external runtime dependencies. It relies solely on standard Java libraries. During development and testing, it uses JUnit (version 4.13.2) as a test dependency.

## Ejemplos de Uso de `SQLParserUtils`

Para ilustrar cómo se utilizan los métodos de utilidad en `SQLParserUtils`, considere el siguiente ejemplo:

```java
// Ejemplo de uso de SQLParserUtils.extractBetweenKeywords
String sql = "SELECT col1 FROM (SELECT col2 FROM table2) WHERE col3 = 1";
String subquery = SQLParserUtils.extractBetweenKeywords(sql, "FROM (", ") WHERE");
System.out.println("Subquery: " + subquery); // Salida: SELECT col2 FROM table2

// Ejemplo de uso de SQLParserUtils.splitTopLevel
String condition = "col1 = 1 AND (col2 = 2 OR col3 = 3)";
List<String> parts = SQLParserUtils.splitTopLevel(condition, "AND");
System.out.println("Parts: " + parts); // Salida: [col1 = 1, (col2 = 2 OR col3 = 3)]
```

Estos ejemplos demuestran cómo las utilidades pueden ayudar a descomponer cadenas SQL complejas para su posterior análisis.
